Thoughts & notes

Short notes from building — the lessons I keep re-learning, written so they can become posts, talks and better specs.

Note · Building

Spec-driven building

Keeping a spec as the single source of truth while an app is built screen by screen. When the spec and the build disagree, stop and decide — don’t let drift decide for you.

Note · Quality

Verification over generation

Generating code is cheap now. Checking a build against its spec — screen by screen, number by number — is the work that makes it done.

Note · Money

Money pacing, in one division

Most budgeting fails on pacing, not totals. Take what’s left after bills, divide by the days left in the month. That one number, checked daily, changes behaviour.
