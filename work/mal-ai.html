MAL AI

Exploring computer vision techniques for malaria parasite image analysis and screening support.

Prototype · research and developmentTensorFlowObject detectionMobile

Overview

At MAL AI I built a mobile application integrating an object-detection model for malaria parasite detection — applying machine learning and computer vision to a real screening workflow on a phone.

Problem

Screening workflows need support that works where the work happens — on mobile devices, in real conditions — without overstating what a model can safely decide.

My role

Mobile application development and object-detection model integration.

Architecture & approach

Object detection with model inference integrated into the mobile application, using on-device processing where supported, so capture and analysis fit a phone-based workflow.

Engineering decisions

This is framed honestly as screening support, not a clinically validated diagnostic product. When a result is uncertain, the system refers to a lab rather than forcing an answer — the same rule I apply to AI support tools: automation earns trust by knowing when to stop.

Challenges

Making a model useful inside a real mobile workflow — inference, capture conditions and the hand-off to human review — rather than as a standalone demo.

Outcome & lessons

A working mobile integration of an object-detection model for malaria parasite screening support, and a lasting rule: never claim diagnostic accuracy without independently verified evidence.
