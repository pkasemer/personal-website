RIZFM

An iOS radio streaming application supported by a custom backend, stream monitoring and production infrastructure.

Live · App StoreSwiftPythonFlaskSQLiteDockerGunicorn
View on the App Store

Overview

RIZFM is a mobile radio application delivering RIZ FM broadcasts to listeners on iOS — “Radio made calm” — backed by a station API with health monitoring.

Problem

Listeners needed a calm, reliable way to find and play stations on a phone, and a dead stream should be caught by the system before a listener finds it.

My role

iOS application and backend API, deployment and stream health monitoring.

Architecture & approach

The iOS app is supported by a Python and Flask API on SQLite, served by Gunicorn and deployed with Docker Compose, exposing station discovery, search, filtering, pagination and featured stations, with individual and aggregate stream health checks and an API health endpoint.

Engineering decisions

Keep simple systems simple: Flask, SQLite, Gunicorn and Docker are all a station directory with health checks actually needs — no message broker, no microservices. Documentation was written after implementation and checked endpoint by endpoint against the running service.

Challenges

App Store review: the app was rejected first, with the reason held on the review page rather than in the email. Reading the reviewer’s actual message before changing anything, fixing what was asked and resubmitting got it live two days later.

Outcome & lessons

Live on the App Store from 21 November 2026 — free, iOS 16.4 and later, Data Not Collected. Shipping is part of the product: the store is another system to engineer around.
